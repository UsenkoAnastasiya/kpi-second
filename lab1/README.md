# Лабораторна 1 — ER-модель домену «Бібліотека»

**Домен:** облік книг, примірників, читачів і видач у міській бібліотеці.

## Структура
- `spec.md` — сутності, атрибути, зв'язки, критерії прийняття (≤1 стор.)
- `model/library.mmd` — ER-модель (Mermaid `erDiagram`)
- `docs/er-diagram.md` — рендер діаграми (GitHub відображає Mermaid автоматично)
- `docs/audit.md` — аудит: топ-3 розбіжності та виправлення
- `adr/` — ключові рішення (MADR)
- `ai/` — промпти до ШІ та аудит його виходу
- `DEFENSE.md` — точка входу для рев'ю

## Рендер у файл (необов'язково)
```
npx -p @mermaid-js/mermaid-cli mmdc -i model/library.mmd -o docs/er-diagram.svg
```

## Межі роботи
Без SQL DDL / ORM — лише концептуальна ER-модель.
