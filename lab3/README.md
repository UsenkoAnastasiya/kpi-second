# Лабораторна 3 — Sequence-діаграми для UC-2 «Видати примірник» (домен «Бібліотека»)

**Домен:** облік книг, примірників, читачів і видач у міській бібліотеці
(той самий, що в [лабораторній 1](../lab1/README.md) і
[лабораторній 2](../lab2/README.md)).

## Що робить ця робота

Деталізує, що відбувається всередині системи в кожному сценарії use case
**UC-2 «Видати примірник»** з лабораторної 2: для кожного з трьох сценаріїв
(S-02, S-03, S-07) побудовано окрему sequence-діаграму.

## Зв'язок з попередніми роботами

- **Лабораторна 1 (дані):** учасники діаграм, що працюють із даними,
  відповідають сутностям READER, BOOK_COPY, LOAN з `lab1/model/library.mmd`.
- **Лабораторна 2 (вимоги, сценарії):** кроки кожної діаграми збігаються з
  Gherkin-сценаріями `lab2/features/loan.feature` та вимогами REQ-02, REQ-03,
  REQ-04, REQ-10.

## Структура

- `spec.md` — UC-2 і його сценарії, учасники, кроки, правила, фрагменти,
  поза обсягом, критерії прийняття (≤1 стор.)
- `docs/sequences.md` — три sequence-діаграми (блоки Mermaid, рендеряться на GitHub)
- `docs/audit.md` — аудит: топ-3 розбіжності та виправлення
- `adr/` — ключові рішення (MADR)
- `ai/prompts.md` — слід промптів і перелік використання ШІ
- `DEFENSE.md` — точка входу для рев'ю

## Сценарії

| Сценарій | Опис                                                        |
| -------- | ----------------------------------------------------------- |
| S-02     | Успішна видача вільного примірника зареєстрованому читачеві |
| S-03     | Відмова: примірник має статус "on_loan"                     |
| S-07     | Відмова: читач не зареєстрований                            |

## Учасники діаграм

Актор: Librarian. Компоненти: LoanController, LoanService,
ReaderRepository, BookCopyRepository, LoanRepository.

## Межі роботи

Лише sequence-діаграми прикладної логіки UC-2; без коду реалізації, SQL і
інфраструктурних механізмів (транзакції БД, конкурентний доступ). Повний
перелік виключень див. у `spec.md`, розділ «Out of scope».
