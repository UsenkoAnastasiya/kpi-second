# Вимоги EARS (v2 - Audited)

| ID         | Вимога у синтаксисі EARS                                                                                                                                                                |
| :--------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **REQ-01** | **WHEN** користувач вводить пошуковий запит, система **SHALL** повернути книги (`Book`), у яких `title`, `isbn` або `full_name` автора містить запит.                                   |
| **REQ-02** | **WHEN** бібліотекар оформлює видачу вільного примірника зареєстрованому читачеві, система **SHALL** створити `Loan` із `loaned_at` = поточна дата та `due_at` = `loaned_at` + 14 днів. |
| **REQ-03** | **IF** `status` примірника (`BookCopy`) не дорівнює "available", **THEN** система **SHALL** відхилити видачу й повідомити причину.                                                      |
| **REQ-04** | **WHEN** `Loan` створено, система **SHALL** встановити `status` відповідного примірника в "on_loan".                                                                                    |
| **REQ-05** | **WHEN** бібліотекар реєструє повернення, система **SHALL** записати поточну дату в `returned_at` відповідного `Loan` і встановити `status` примірника в "available".                   |
| **REQ-06** | **WHEN** до `due_at` лишається 2 дні й `returned_at` порожній, система **SHALL** надіслати `Notification Service` запит на нагадування на `email` читача.                               |
| **REQ-07** | **WHILE** `returned_at` `Loan` порожній і поточна дата пізніша за `due_at`, система **SHALL** показувати цей `Loan` у звіті прострочених видач для бібліотекаря.                        |
| **REQ-08** | **WHEN** `Loan` стає простроченим, система **SHALL** надіслати `Notification Service` запит на сповіщення про прострочення на `email` читача.                                           |
| **REQ-09** | **WHEN** читач відкриває свої видачі, система **SHALL** показати його `Loan` із `title` книги, `loaned_at`, `due_at`, `returned_at`.                                                    |
| **REQ-10** | **IF** `Reader` із зазначеним ідентифікатором не існує в системі, **THEN** система **SHALL** відхилити видачу й повідомити, що читача не зареєстровано.                                 |
