# User Stories

- **US-01:** Як Бібліотекар, я хочу оформлювати видачу примірника книги читачеві, щоб вести облік виданих книг.
- **US-02:** Як Читач, я хочу отримувати сповіщення за 2 дні до закінчення терміну оренди, щоб вчасно повернути книгу.
- **US-03:** Як Бібліотекар, я хочу фіксувати повернення примірника, щоб звільнити його для інших читачів.
